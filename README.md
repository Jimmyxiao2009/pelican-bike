# 鹈鹕骑自行车

一个使用 SVG、CSS 与原生 JavaScript 绘制的单页动画实验：鹈鹕沿海岸骑行，脚踏、车轮和肢体随时间联动，页面提供暂停与继续按钮。

## 运行

直接用浏览器打开 `index.html`，或在仓库目录运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

所有页面、样式、SVG 和脚本都在 `index.html` 中，无需安装前端依赖或执行构建。
